## Technical approach

The portfolio is intentionally a lightweight static site:

- no frontend framework
- no runtime JavaScript dependencies
- no external icon/font libraries
- responsive CSS
- semantic HTML and keyboard focus states
- reduced-motion support
- SEO/social metadata and Person structured data

That keeps the page fast, portable, and easy to host on GitHub Pages.
